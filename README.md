# OKCRecordCA2
Second Year Web Application project that displays the Oklahoma City Thunder NBA record from 2019-2020 to the 2024-2025 season.
This application allows records to be managed with CRUD operations such as creating new records and deleting records as well as Chart display of the records.

# Requirements
NPM
Node.js
MongoDB

# Technologies
HTML
CSS
Javascript
EJS
Node.js
MongoDB
Mongoose
Chart.js


# Setup

 # Install dependencies
   npm install

 # Start MongoDB
  Ensure MongoDB is running as background service

 # Seed database
   node seeds.js 
 # Start Application 
   node app.js
   Application is available on port 3000
